# 사진 5MB 이하로 줄이기

## 사용법 (Windows)

1. `input` 폴더에 사진을 전부 넣습니다. (개수 제한 없음, 하위 폴더도 가능)
2. `실행하기.bat` 을 더블클릭합니다.
3. 끝나면 `output` 폴더에 결과가 생깁니다. 이 폴더의 사진을 업로드하면 됩니다.

> 처음 한 번은 Python 이 필요합니다. 없다고 나오면 https://python.org 에서 설치하고
> 설치 화면에서 **"Add python.exe to PATH"** 를 꼭 체크하세요.
> 필요한 프로그램(Pillow)은 처음 실행할 때 자동으로 설치됩니다.

Mac 은 터미널에서 이 폴더로 이동한 뒤 `pip3 install pillow pillow-heif` 후 `python3 resize.py`.

## 어떻게 줄이나요?

- **5MB 이하 사진은 전혀 건드리지 않고** 그대로 `output` 에 복사합니다.
- 5MB 넘는 사진만 줄입니다.
  1. 해상도는 그대로 두고 JPEG 품질을 95 → 85 사이에서 **5MB 안에 들어가는 가장 높은 값**으로 저장
  2. 품질 85 로도 안 들어가면(48MP 같은 초고화소 사진) 그때만 해상도를 필요한 만큼 줄임
- 결과는 4.9MB 이하로 만들어서 사이트 기준이 조금 달라도 걸리지 않게 했습니다.
- 촬영 날짜·회전 정보(EXIF)와 색상 프로필은 그대로 유지됩니다.
- PNG / HEIC(아이폰) 등 JPG 가 아닌 큰 사진은 `.jpg` 로 바뀌어 저장됩니다.

다시 실행할 때는 `output` 폴더를 비우고 실행하는 것을 권장합니다.
