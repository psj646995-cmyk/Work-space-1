# 후원 아동 감사레터 자동 전사 도구

후원 아동이 후원자에게 쓴 손글씨 감사레터(PDF 또는 JPG/PNG 사진, 350~400개)를
Claude 구독(Pro 플랜)만으로 자동 전사하고, 판독 신뢰도·언어·내용 정책(부적절한
요청 등) 플래그를 함께 매겨 보기 좋은 HTML 리포트로 정리해주는 도구입니다.
별도 API 과금은 발생하지 않습니다.

## 사전 준비 (한 번만 하면 됨)

1. **Python 3.9 이상** 설치. Windows는 `python.org/downloads`에서 설치 파일을 받아
   설치하되, 설치 화면에서 **"Add python.exe to PATH"** 체크박스를 꼭 체크하세요.
2. **Claude Code CLI** 설치 및 Pro 구독 계정으로 로그인. 아무 폴더에서나 명령
   프롬프트를 열고 `claude`를 입력하면 로그인 절차가 안내됩니다.

## 폴더 구조

```
handwriting-extraction/
├── 실행하기.bat           # (Windows) 더블클릭으로 바로 실행
├── input_pdfs/            # 여기에 PDF 또는 JPG/JPEG/PNG 파일들을 넣으세요
├── output/
│   ├── results.html       # 브라우저로 열어보는 최종 리포트
│   ├── results.csv        # 메모장/엑셀에 바로 복사·붙여넣기용
│   └── results.jsonl      # 내부 데이터(재개 판단용, 사람이 직접 볼 필요 없음)
├── extract.py
└── README.md
```

## 사용 방법

### 1) 파일 넣기

파일 탐색기에서 `input_pdfs` 폴더를 열고, 처리하고 싶은 파일들을 그대로
드래그해서 넣으세요. **PDF, JPG, JPEG, PNG 모두 지원**하며, 한 폴더 안에
섞여 있어도 됩니다. (일반 파일 복사와 동일합니다.) 처음에는 전체를
한 번에 넣기보다, 5~10개만 넣고 아래 2)~3)을 먼저 해보는 걸 권장합니다 —
결과 품질을 확인한 뒤 나머지를 마저 넣고 다시 실행하면 됩니다.

### 2) 실행하기

**`실행하기.bat` 파일을 더블클릭**하세요. 검은 창(명령 프롬프트)이 열리고
자동으로 처리가 시작됩니다. 명령어를 직접 입력할 필요가 없습니다.

(Mac/Linux를 쓰신다면 터미널에서 `cd handwriting-extraction && python3 extract.py`
를 실행하면 동일하게 동작합니다.)

### 3) 그냥 창을 열어두세요 — 사용량 한도에 자동 대응

Pro 플랜은 5시간/주간 사용량 한도가 있습니다. 처리 도중 한도에 걸리면
스크립트가 **멈추지 않고**, 한도가 풀릴 것으로 보이는 시각까지 자동으로
기다렸다가 스스로 다시 시도합니다. 창에 "...아직 대기 중입니다" 같은
메시지가 주기적으로 뜨는 게 정상이며, 그냥 그대로 컴퓨터를 켜두시면
됩니다. (한도가 정확히 언제 풀리는지 CLI가 알려주지 않는 경우엔 기본값으로
30분마다 재시도합니다.)

그만두고 싶으면 창을 그냥 닫거나 `Ctrl+C`를 누르면 됩니다. 그때까지
처리된 결과는 이미 리포트에 저장되어 있고, 나중에 `실행하기.bat`을
다시 더블클릭하면 처리된 파일은 건너뛰고 남은 파일부터 이어서 처리됩니다.

### 4) 결과 확인

`output` 폴더에 두 가지 결과 파일이 생깁니다. 둘 다 배치가 끝날 때마다
최신 상태로 자동 갱신됩니다.

- **`results.html`** — 더블클릭하면 브라우저로 열리는 보기 좋은 리포트.
  신뢰도 막대, 확인필요/플래그 표시가 한눈에 보입니다.
- **`results.csv`** — 더블클릭하면 보통 엑셀로 바로 열립니다. 메모장으로
  열어도 되고, 전체를 선택(Ctrl+A)해서 복사(Ctrl+C)한 뒤 엑셀이나 다른
  문서에 붙여넣기(Ctrl+V) 하기에 좋은 형식입니다.

## 결과 리포트 (`output/results.html`) 구성

상단에 전체 처리 건수 / 통과 / 확인필요 / 내용 플래그 건수 요약이 나오고,
그 아래 레터별로 다음 정보가 카드 형태로 정리됩니다.

| 항목 | 설명 |
|---|---|
| 파일명 | 원본 파일명 (PDF/JPG/PNG) |
| 전사 텍스트 | 손글씨를 옮긴 텍스트 (쓰여진 언어 그대로, 번역하지 않음) |
| 신뢰도 | Claude가 매긴 판독 신뢰도 (0~100%), 막대로 표시 |
| 확인필요 | 신뢰도가 90% 미만이면 표시 — 사람이 원본과 대조 확인 필요 |
| 언어 태그 | 영어가 아닌 언어로 판단되면 표시 (예: Chichewa) |
| 내용 플래그 | 금전/선물 요청, 개인연락처 교환 요청, 만남 약속 요청 등 감사레터에 부적절해 보이는 내용이 있으면 표시 + 사유 |

리포트는 **내용 플래그 → 확인필요 → 나머지** 순으로 정렬되어, 위에서부터
훑으면 우선순위가 높은 항목부터 검토할 수 있습니다. 단, 이 판정은 참고용
스크리닝이며 최종 판단은 반드시 사람이 직접 편지 내용을 확인 후 내려야
합니다.

### 참고: 현지어로 쓰인 편지

일부 편지가 영어가 아니라 아동의 현지어(예: 말라위의 Chichewa)로 쓰여
있을 수 있습니다. 이런 편지는 전사는 시도하되(번역은 하지 않음) 신뢰도가
구조적으로 낮게 나오도록 설계되어 있어(`언어` 태그 + `확인필요` 자동
표시), 리포트를 열어보면 바로 눈에 띕니다. 현지어 편지 비율이 높다면,
별도로 번역까지 자동화할지는 추가로 논의가 필요합니다.

## 문제 해결

- **"이 배치 처리 중 오류 발생... [WinError 2]"** 가 모든 배치에서 반복되면
  `claude` CLI를 찾지 못한 것입니다. 명령 프롬프트를 새로 열어
  `claude --version`을 입력했을 때 정상적으로 버전이 나오는지 확인하세요.
  (최신 버전에서는 이 경우 스크립트가 배치를 시도하기 전에 바로 알려줍니다.)
- **"claude CLI를 찾을 수 없습니다"** — 위와 동일한 원인입니다. `claude` 설치와
  로그인을 다시 확인해주세요.
- **"경고: 응답에 '...' 결과가 없습니다"가 배치의 파일마다 전부 뜨는 경우** —
  이전 버전의 프롬프트 문구 때문에 생기던 버그로, 최신 버전에서 고쳤습니다.
  최신 코드로 다시 받아서 실행해보세요. 그래도 재현되면 `output/debug_last_batch.txt`
  파일(가장 최근 배치의 원본 응답이 저장됨)의 내용을 복사해서 알려주시면
  원인을 바로 확인할 수 있습니다.

## 설정 조정

`extract.py` 상단의 설정값을 필요에 따라 바꿀 수 있습니다.

- `BATCH_SIZE` — 한 번의 Claude 호출에 묶을 파일 개수 (기본 8). 사용량을
  아끼려면 늘리고, 개별 파일 처리 안정성을 높이려면 줄이세요.
- `CONFIDENCE_THRESHOLD` — 이 값 미만이면 `확인필요`로 표시됩니다 (기본 90).
- `DEFAULT_RETRY_WAIT_SECONDS` — 사용량 한도 메시지에서 정확한 재개 시각을
  못 찾았을 때 기본으로 기다리는 시간(초, 기본 30분).
- `DOMAIN_HINT` — 편지 내용의 특성(예: 아동 나이대, 흔한 철자 실수 패턴 등)을
  한 줄로 적어두면 판독 정확도를 높이는 데 도움이 됩니다.
