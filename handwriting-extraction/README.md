# 후원 아동 감사레터 자동 전사 도구

후원 아동이 후원자에게 쓴 손글씨 감사레터 PDF(350~400개)를 Claude 구독(Pro 플랜)만으로
자동 전사하고, 판독 신뢰도·언어·내용 정책(부적절한 요청 등) 플래그를 함께 매겨
보기 좋은 HTML 리포트로 정리해주는 스크립트입니다. 별도 API 과금은 발생하지 않습니다.

## 사전 준비

1. **Python 3.9 이상** 설치 확인
   ```
   python3 --version
   ```
2. **Claude Code CLI** 설치 및 Pro 구독 계정으로 로그인
   ```
   claude --version
   claude
   ```
   (처음이면 `claude` 실행 시 로그인 절차가 안내됩니다.)

## 폴더 구조

```
handwriting-extraction/
├── input_pdfs/           # 여기에 PDF 파일들을 넣으세요
├── output/
│   ├── results.html      # 브라우저로 열어보는 최종 리포트
│   └── results.jsonl     # 내부 데이터(재개 판단용, 사람이 직접 볼 필요 없음)
├── extract.py
└── README.md
```

## 사용 방법

### 1) 시범 실행 (권장)

전체 350~400개를 한 번에 돌리기 전에, 먼저 PDF 5~10개만 `input_pdfs/`에 넣고
아래 명령을 실행해보세요.

```
cd handwriting-extraction
python3 extract.py
```

실행이 끝나면 `output/results.html`을 브라우저로 열어서:
- 전사된 텍스트가 원본과 얼마나 일치하는지 몇 건 직접 대조
- `신뢰도` 값이 실제 글씨 상태와 맞는지
- `내용 플래그` 판단이 합리적인지

확인하세요. 품질이 만족스럽지 않으면 이 세션에서 `extract.py`의 프롬프트
(`build_prompt` 함수)를 함께 조정할 수 있습니다.

### 2) 전체 실행

시범 실행 결과가 괜찮으면, 나머지 PDF들을 모두 `input_pdfs/`에 넣고 다시
`python3 extract.py`를 실행하세요. 이미 처리된 파일은 자동으로 건너뛰고
새 파일만 처리하며, 배치가 끝날 때마다 `results.html`이 최신 상태로
다시 생성됩니다.

### 3) 사용량 한도에 걸렸을 때

Pro 플랜은 5시간/주간 사용량 한도가 있습니다. 스크립트가 한도 관련 오류를
감지하면 안내 메시지를 출력하고 안전하게 중단합니다. **그때까지 처리된
결과는 이미 리포트에 반영되어 있습니다.** 한도가 초기화된 뒤(보통 몇
시간~다음 날) 같은 명령(`python3 extract.py`)을 다시 실행하면 남은
파일부터 이어서 처리됩니다. 며칠에 걸쳐 나눠 실행해도 무방합니다.

## 결과 리포트 (`output/results.html`) 구성

상단에 전체 처리 건수 / 통과 / 확인필요 / 내용 플래그 건수 요약이 나오고,
그 아래 레터별로 다음 정보가 카드 형태로 정리됩니다.

| 항목 | 설명 |
|---|---|
| 파일명 | 원본 PDF 파일명 |
| 전사 텍스트 | 손글씨를 옮긴 텍스트 (쓰여진 언어 그대로, 번역하지 않음) |
| 신뢰도 | Claude가 매긴 판독 신뢰도 (0~100%), 막대로 표시 |
| 확인필요 | 신뢰도가 90% 미만이면 표시 — 사람이 원본과 대조 확인 필요 |
| 언어 태그 | 영어가 아닌 언어로 판단되면 표시 (예: Chichewa) |
| 내용 플래그 | 금전/선물 요청, 개인연락처 교환 요청, 만남 약속 요청 등 감사레터에 부적절해 보이는 내용이 있으면 표시 + 사유 |

리포트는 **내용 플래그 → 확인필요 → 나머지** 순으로 정렬되어, 위에서부터
훑으면 우선순위가 높은 항목부터 검토할 수 있습니다. 단, 이 판정은 참고용
스크리닝이며 최종 판단은 반드시 사람이 직접 편지 내용을 확인 후 내려야
합니다.

### 참고: 현지어로 쓰인 편지

시범 처리 중 일부 편지가 영어가 아니라 아동의 현지어(예: 말라위의
Chichewa)로 쓰여 있을 수 있다는 것이 확인되었습니다. 이런 편지는 전사는
시도하되(번역은 하지 않음) 신뢰도가 구조적으로 낮게 나오도록 설계되어
있어(`언어` 태그 + `확인필요` 자동 표시), 사람이 우선적으로 대조·번역
확인을 할 수 있습니다. 현지어 편지 비율이 높다면, 별도로 번역까지
자동화할지는 추가로 논의가 필요합니다.

## 설정 조정

`extract.py` 상단의 설정값을 필요에 따라 바꿀 수 있습니다.

- `BATCH_SIZE` — 한 번의 Claude 호출에 묶을 PDF 개수 (기본 8). 사용량을
  아끼려면 늘리고, 개별 파일 처리 안정성을 높이려면 줄이세요.
- `CONFIDENCE_THRESHOLD` — 이 값 미만이면 `확인필요`로 표시됩니다 (기본 90).
- `DOMAIN_HINT` — 편지 내용의 특성(예: 아동 나이대, 흔한 철자 실수 패턴 등)을
  한 줄로 적어두면 판독 정확도를 높이는 데 도움이 됩니다.
