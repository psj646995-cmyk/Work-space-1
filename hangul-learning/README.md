# 한글 탐험대

6–7세 아이를 위한 한글 조합 놀이. `index.html` 하나만 브라우저(크롬/사파리/엣지)로 열면 됩니다.

- 자음을 누르면 이름(ㄱ → "기역"), 모음을 붙이면 글자(ㄱ+ㅏ → "가"), 받침까지 붙이면 "각" 소리가 납니다.
- **인터넷 없이 동작합니다.** 글꼴(Jua, Gowun Dodum — SIL Open Font License 1.1)이 파일 안에 들어 있어서 이 파일 하나만 복사하면 됩니다.
- 소리는 컴퓨터에 설치된 한국어 음성을 씁니다(오프라인에서도 되는 음성을 먼저 고릅니다).
  - 윈도우: 설정 → 시간 및 언어 → 언어 및 지역 → 한국어 추가 시 "음성" 항목 포함 (보통 한국어 윈도우에는 이미 있음)
  - 맥: 기본으로 들어 있는 한국어 음성(Yuna 등) 사용
- 미션(그림 보고 글자 만들기), 보물 도감(한 글자 진짜 단어 52개), 만든 글자 수 별점이 있습니다. 진행 상황은 그 브라우저에만 저장됩니다.
- 쌍자음(ㄲ ㄸ ㅃ ㅆ ㅉ)과 어려운 모음(ㅐ ㅔ ㅘ …)은 "더 보기" 스위치로 켭니다.

## 아이패드·핸드폰에서 쓰기

파일 앱·카카오톡·구글 드라이브에서 html 파일을 누르면 **미리보기**로만 열려서 단추가 안 나오고 눌리지도 않습니다.
인터넷 주소로 열어야 합니다.

1. (처음 한 번) GitHub 저장소 → Settings → Pages → Source: "Deploy from a branch",
   Branch: `claude/determined-cray-5qprnn`, 폴더 `/ (root)` → Save
2. 1~2분 뒤 패드의 사파리에서 `https://psj646995-cmyk.github.io/Work-space-1/hangul-learning/` 열기
3. 공유 버튼 → **홈 화면에 추가** → 이제 앱 아이콘으로 실행되고, 한 번 연 뒤에는 인터넷 없이도 동작합니다.

`index.html`을 고친 뒤에는 `sw.js`의 `VERSION`을 올려야 기기에 새 버전이 들어갑니다.
