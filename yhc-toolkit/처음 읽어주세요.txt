==================================================
 YHC 도구모음 - 처음 읽어주세요
==================================================

이 폴더에는 프로그램 3개가 들어 있습니다.

  A_크리스마스카드 프로그램   : 아동 사진+그림+편지 문구를 편지지에 합성
  B_글자추출 프로그램         : 손글씨 감사레터를 글자로 옮겨 리포트로 정리
  C_사진용량 줄이기 프로그램  : 5MB 넘는 사진만 화질 유지하며 5MB 이하로

각 폴더 안의 "실행하기.bat" 을 더블클릭하면 실행됩니다.
검은 창에 진행 상황이 차례로 나오고, 문제가 있으면 [ERROR] 로 이유가 표시됩니다.


--------------------------------------------------
 필요한 것 (유료 여부)
--------------------------------------------------

  A 크리스마스카드  : Python 만 있으면 됨 (무료)
  B 글자추출        : Python + Claude Code + 유료 Claude 구독(Pro 이상)
  C 사진용량 줄이기 : Python 만 있으면 됨 (무료)

  * 추가로 필요한 프로그램 구성요소는 처음 실행할 때 자동으로 설치됩니다.
    (처음 한 번은 인터넷 연결이 필요합니다)


--------------------------------------------------
 [공통] Python 설치 (한 번만)
--------------------------------------------------

1. https://www.python.org/downloads/ 에서 Python 을 받아 설치합니다.
2. 설치 첫 화면에서 "Add python.exe to PATH" 를 꼭 체크한 뒤 Install.

이미 설치했는데 "No working Python was found" 가 나오면:
  Windows 설정 > 앱 > 고급 앱 설정 > 앱 실행 별칭 에서
  "python.exe", "python3.exe" 를 끄고 다시 실행하세요.
  (Windows 에 들어 있는 가짜 python 바로가기가 진짜를 가리는 경우입니다)


==================================================
 A. 크리스마스카드 프로그램
==================================================

1. 편지 문구 엑셀(.xlsx)을 "A_크리스마스카드 프로그램" 폴더 바로 안에 넣습니다.
   - 파일 이름은 아무거나 괜찮지만, 엑셀 파일은 1개만 두세요.
   - 첫 시트에 열 제목 3개가 있어야 합니다:
       Child's ID  /  Child's Name  /  Letter
2. photos 폴더에 아동 사진, drawings 폴더에 아동 그림을 넣습니다.
   - 파일 이름이 아동 ID 로 시작해야 합니다. (예: MWI0040003.jpg)
   - 띄어쓰기/하이픈/대소문자 차이는 자동으로 무시합니다.
3. 실행하기.bat 더블클릭.
4. 결과: output 폴더
   - ID_이름.jpg            : 완성된 편지
   - mismatch_report.html   : 사진/그림/문구가 빠진 아동, 경고 목록

  * 엑셀을 Excel 에서 열어둔 채로 실행하면 오류가 납니다. 닫고 실행하세요.
  * 이미 만들어진 아동은 건너뜁니다. 다시 만들려면 output 에서 지우세요.


==================================================
 B. 글자추출 프로그램  (유료 Claude 구독 필요)
==================================================

[처음 한 번만]
1. Claude Code 설치: 시작 메뉴에서 "PowerShell" 을 열고 아래를 붙여넣고 Enter
       irm https://claude.ai/install.ps1 | iex
2. 명령 프롬프트(cmd)를 새로 열고  claude  입력 후 Enter
   → 안내에 따라 유료(Pro 이상) Claude 계정으로 로그인합니다.

[사용법]
1. input_pdfs 폴더에 손글씨 편지 파일(PDF, JPG, PNG)을 넣습니다.
   처음엔 5~10개로 먼저 시험해 보는 것을 권장합니다.
2. 실행하기.bat 더블클릭. 창을 닫지 말고 그대로 두세요.
   - 사용량 한도에 걸리면 알아서 기다렸다가 다시 시작합니다.
   - 중간에 닫아도, 다시 실행하면 남은 파일부터 이어서 합니다.
3. 결과: output 폴더
   - results.html : 브라우저로 보는 리포트 (확인필요/플래그 표시)
   - results.csv  : 엑셀로 열어 복사/붙여넣기용

  * 판정은 참고용입니다. 최종 확인은 꼭 사람이 직접 해주세요.


==================================================
 C. 사진용량 줄이기 프로그램
==================================================

1. input 폴더에 사진을 전부 넣습니다. (개수 제한 없음, 폴더째 넣어도 됨)
2. 실행하기.bat 더블클릭.
3. output 폴더의 사진을 그대로 업로드하면 됩니다.

[어떻게 줄이나요]
  - 5MB 이하 사진은 전혀 건드리지 않고 그대로 output 에 복사합니다.
  - 5MB 넘는 사진만 줄입니다.
      1) 해상도는 그대로 두고 화질을 95~85 중 가장 높은 값으로 저장
      2) 그래도 크면(초고화소 사진) 그때만 해상도를 필요한 만큼 줄임
  - 결과는 여유 있게 4.9MB 이하로 만듭니다.
  - 촬영 날짜, 회전 정보, 색감은 유지됩니다.
  - PNG / 아이폰 HEIC 처럼 JPG 가 아닌 큰 사진은 .jpg 로 바뀝니다.
  - 처리 기록은 log.txt 에 저장됩니다. 문제가 생기면 이 내용을 알려주세요.
  - 다시 실행할 때는 output 폴더를 비우고 실행하는 것을 권장합니다.
